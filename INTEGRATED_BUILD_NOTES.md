# MeshFlattener Pro Integrated Build

This package merges v1-v4 modules into a unified Electron + React + Three.js desktop application.

Included systems:
- STL Viewer
- Mesh Flatten Engine
- Seam Editor
- Multi Panel Manager
- Nesting Optimizer
- PDF Export Utilities
- Zustand State Stores

Build:
1. Install Node.js 20+
2. Run npm install
3. Run npm run electron-dev
4. Build installer: npm run build-electron
